# KR/EN i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (or subagent-driven-development). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 공개 사이트에 `/ko`·`/en` URL + 쿠키 기반 KR/EN 전환을 구현하고, 정적 카피는 메시지 사전·CMS는 Gemini+TranslationCache로 번역한다.

**Architecture:** Next.js App Router `[locale]` 세그먼트 + 미들웨어 리다이렉트. 정적 UI는 `messages/ko|en`. CMS는 서버 `translateCached()` → Prisma 캐시 → Gemini.

**Tech Stack:** Next.js 16, Prisma, Gemini generateContent API, node:test

## Global Constraints

- Admin `/admin/*` 비로케일·비번역
- `GEMINI_API_KEY` 없으면 원문 폴백
- next-intl 미도입
- 소스 언어 가정: `ko`
- 쿠키명: `NEXT_LOCALE`
- 기본 locale: `ko`
- Feature branch + PR (main 직접 장기 WIP 금지)
